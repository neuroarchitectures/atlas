# Inception (GoogLeNet)

## Overview

GoogLeNet/Inception: multi-scale parallel convolutions within a single module (1x1, 3x3, 5x5, pooling) for efficient deep vision networks.

- **Year:** 2015
- **Authors:** Szegedy et al.
- **Source:** arXiv:1409.4842
- **Category:** Computer Vision
