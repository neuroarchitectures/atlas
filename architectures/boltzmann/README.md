# Boltzmann Machine

## Overview

Stochastic energy-based network with visible and hidden units, using simulated annealing for sampling from a Boltzmann distribution.

- **Year:** 1985
- **Authors:** Ackley et al.
- **Source:** Cognitive Science 1985
- **Category:** NLP
