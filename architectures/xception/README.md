# Xception

## Overview

Xception: extreme version of Inception where depthwise separable convolutions replace the Inception module entirely, separating spatial and channel-wise computation.

- **Year:** 2017
- **Authors:** Chollet
- **Source:** arXiv:1610.02357
- **Category:** Computer Vision
