## Related

**Predecessors:**
- DeepWalk (Perozzi et al., 2014) — Skip-gram on random walks; transductive node embedding
- LINE (Tang et al., 2015) — First/second-order proximity for large-scale network embedding
- node2vec (Grover & Leskovec, 2016) — Biased random walks generalizing DeepWalk
- Graphlet-based network analysis (Milo et al., 2002; Pržulj, 2007) — Manual structural feature extraction

**Successors:**
- GraphSAGE (Hamilton et al., 2017) — Inductive representation learning via neighborhood sampling and aggregation
- GCN (Kipf & Welling, 2017) — Spectral graph convolution networks; end-to-end trainable
- GAT (Veličković et al., 2018) — Graph attention networks with learned neighbor weights

**Alternatives:**
- GraRep (Cao et al., 2015) — Global structural representation via k-order proximity matrices
- HARP (Chen et al., 2017) — Hierarchical representation learning for networks
