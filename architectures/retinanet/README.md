# RetinaNet

## Overview

RetinaNet: single-stage object detector using Focal Loss to address class imbalance, achieving two-stage accuracy at one-stage speed.

- **Year:** 2017
- **Authors:** Lin et al.
- **Source:** arXiv:1708.02002
- **Category:** Computer Vision
