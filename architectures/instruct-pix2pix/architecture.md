# Architecture: InstructPix2Pix

## Motivation

Text-to-image diffusion models can generate but not edit existing images. Editing requires either inversion or masks.

## Core Idea

Train a conditional diffusion model on pairs of (source image, instruction, edited image) generated by GPT-3 and Stable Diffusion, enabling instruction-based editing without inversion.

### Components

1. **Source image latent** — VAE encoding of input image. 2. **CLIP text encoder** — Encodes editing instruction. 3. **Conditional UNet** — Diffusion model conditioned on both source latent and instruction text. 4. **Two-channel conditioning** — Source image and text both as conditions.

### Data Flow

1. **Input** — The input is fed into the first layer.
2. **Forward pass** — Each layer processes its input and passes the result to the next layer.
3. **Output** — The final layer produces the model's prediction.
