# Autoencoder

## Overview

Encoder-decoder network that learns compressed representations by reconstructing its input through a bottleneck.

- **Year:** 1986
- **Authors:** Rumelhart et al.
- **Source:** Parallel Distributed Processing 1986
- **Category:** NLP
