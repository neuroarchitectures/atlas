## Related

**Predecessors:**
- DeepWalk (Perozzi et al., 2014) — Skip-gram on random walks; single-dimension
- LINE (Tang et al., 2015) — First/second-order proximity; single-dimension
- node2vec (Grover & Leskovec, 2016) — Biased random walks; single-dimension
- Metapath2vec (Dong et al., 2017) — Heterogeneous network embedding via meta-path random walks
- Multi-dimensional network analysis (Berlingerio et al., 2011) — Measures for multidimensional networks

**Successors:**
- MNE (Zhang et al., 2018) — Multi-network embedding with stable identities
- R-GCN (Schlichtkrull et al., 2018) — Relational graph convolutional networks for multi-relational data
- HIN2Vec (Fu et al., 2017) — Heterogeneous information network embedding

**Alternatives:**
- GraRep (Cao et al., 2015) — Global structural representation via k-order proximity
- SDNE (Wang et al., 2016) — Deep autoencoder for network embedding; single-dimension
