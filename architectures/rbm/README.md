# Restricted Boltzmann Machine

## Overview

Bipartite energy-based model with visible and hidden layers, no intra-layer connections, enabling efficient contrastive divergence training.

- **Year:** 1986
- **Authors:** Smolensky
- **Source:** Parallel Distributed Processing 1986
- **Category:** NLP
