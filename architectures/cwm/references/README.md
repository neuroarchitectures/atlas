## Related

- **Liquid Time-Constant Networks (LTCNs)** — Neurons governed by time-varying differential equations; biologically inspired neural dynamics.
- **Spiking Neural Networks (SNNs)** — Use discrete, timed events; CTM abstracts these into a differentiable framework.
- **PonderNet / Adaptive Computation Time (ACT)** — Learnable halting modules; CTM's adaptive compute emerges naturally without dedicated halting components.
- **Recurrent Models of Visual Attention (RAM)** — Sequential processing of visual glimpses; CTM's novelty is using neural synchronization as primary representation.
- **Recurrent Independent Mechanisms (RIMs)** — Modular, asynchronous sub-networks for multi-step reasoning.
- **U-Net** — The synapse model uses a U-Net-esque MLP for deeper synaptic computation.
- **ResNet** — Used as the feature extractor providing keys/values for cross-attention.
- **Transformer** — Cross-attention mechanism used for observation; CTM uses synchronization rather than static snapshots.
